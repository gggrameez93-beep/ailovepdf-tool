How to Use AiLovePDF Tools

Our platform is designed for simplicity. Because all processing happens on your device (Client-Side), the steps are fast and straightforward. Follow these instructions to master every tool.

How to Merge PDF

  1. Click on the Merge PDF card on the home page.
  2. Click the "Choose Files" button and select two or more PDF documents from your computer or phone.
  3. Click the blue Execute button.
  4. The tool will instantly combine the files and download a new document named AiLovePDF_Merged.pdf.

How to Compress PDF

  1. Select the Compress PDF tool.
  2. Upload the large PDF file you want to shrink.
  3. From the dropdown menu, select your preferred quality (Medium for standard use, Low for strict size limits like 100KB).
  4. Click Execute. Wait a few moments as your browser optimizes the file, then it will download automatically.

How to Split PDF

  1. Open the Split PDF tool.
  2. Upload your multi-page document.
  3. In the text box, enter the specific page numbers you want to extract, separated by commas (e.g., 1, 4, 7).
  4. Click Execute to generate a new PDF containing only those pages.

How to Delete PDF Pages

  1. Select the Delete Pages tool.
  2. Upload the document that contains unwanted or blank pages.
  3. Type the page numbers you wish to remove (e.g., 2, 5).
  4. Hit Execute. The tool will strip those pages and download the cleaned document.

How to use Converters (JPG/TXT to PDF)

  • JPG to PDF: Upload one or more image files (JPG/PNG). The tool will place them onto standard PDF pages and download the file.
  • PDF to JPG: Upload a PDF. The tool will convert the pages into high-quality JPG image files.
  • TXT to PDF: Upload any plain .txt file. The engine will format the text and generate a secure, non-editable PDF document.
